# AutoZK

> 通用桌面自动化工具 —— 拒绝重复，从我做起。

AutoZK 是一款基于 Electron 的跨平台桌面自动化（RPA）工具，面向需要重复执行鼠标点击、键盘输入与评论发送的场景。通过「录制坐标 + 绑定快捷键」的方式，把一套重复操作固化成任务，按下快捷键即可自动执行，并可串联多个任务形成自动化流水线。

## 功能特性

### 自动工作流

以任务卡片为核心，每个任务可绑定一个全局快捷键，支持三种工作模式：

| 模式 | 说明 | 标识色 |
| --- | --- | --- |
| 发评论 | 复制评论 → 点击水军位置 → 粘贴 → 回车，循环发送 | 黄色 |
| 操作鼠标 | 按顺序移动并点击捕获的坐标，支持一次性 / 循环 | 绿色 |
| 混合操作 | 评论前操作 → 发送评论 → 评论后操作 | 粉色 |

- **全局快捷键**：任务快捷键在窗口失焦时依然生效，可在操作其他应用时启动 / 停止任务；支持纯键盘热键（含小键盘、纯修饰键组合）与含鼠标按键的热键。
- **操作规则**：一次性（按顺序点击完即结束）或循环（循环点击，再次按快捷键结束）。
- **必发评论**：评论列表可逐条开启「必发」，该条评论在运行中必定被发送。
- **独立延迟**：每条评论、每个操作步骤均可单独设置延迟时间，支持批量设置。
- **任务联动**：主任务自然结束后，可按设定的延迟自动触发一个或多个联动任务，形成执行链；联动任务支持拖拽排序。
- **草稿箱**：配置未完成的任务可先存为草稿，后续编辑完成后转为正式任务。

### 水军设置

管理用于点击的屏幕坐标（「水军」），支持坐标捕获、批量编辑与多选删除。任务运行时依次点击这些坐标完成交互。

### 评论表格

集中管理评论内容，支持手动录入与表格选择两种来源、拖拽排序、导入 / 导出，点击评论即可复制。

### 分组管理

采用「外层分组 → 互动分组 → 任务」三级结构：

- **外层分组**：任务的粗粒度分类容器。
- **互动分组**：成套任务的集合，是快捷键生效的最小单位。
- **启用分组**：全局唯一决定当前哪一套（互动分组）任务的快捷键生效，其余分组仅用于切换视图与预览。

### 批量操作

支持多选批量删除、批量导出与批量导入任务（`.azk` 文件），导入时自动补全缺失的评论内容。

### 其他

- **坐标捕获**：独立置顶弹窗，可在整个屏幕（含任务栏）范围获取鼠标绝对坐标。
- **通知弹窗**：任务开始 / 结束以悬浮通知提示，最多同时显示 2 条。
- **数据持久化**：任务、水军、评论、分组等数据经 `electron-store` 保存到本地，重启不丢失。
- **界面设置**：全局字体大小实时调节、全屏指针获取热键自定义。

## 技术栈

- **框架**：Electron 28 + Vue 3 + TypeScript
- **UI**：Element Plus + `@element-plus/icons-vue`
- **状态管理**：Pinia
- **构建**：Vite + electron-builder
- **自动化能力**：`robotjs`（鼠标键盘模拟）、`uiohook-napi`（系统级键鼠事件监听）、`screenshot-desktop`（屏幕信息）
- **本地存储**：`electron-store`
- **其他**：`vue-router`、`vuedraggable`

## 快速开始

### 环境要求

- Node.js 18+
- Windows / macOS / Linux
- 原生模块（`robotjs`、`uiohook-napi`）需要本地编译环境：
  - Windows：Visual Studio Build Tools（含 C++ 桌面开发）
  - macOS：Xcode Command Line Tools
  - Linux：`build-essential`、`libx11-dev` 等

### 安装与运行

```bash
# 安装依赖
npm install

# 开发模式（同时启动主进程与渲染进程）
npm run dev

# 构建
npm run build

# 打包安装程序（输出到 release/）
npm run dist          # 默认 NSIS 安装包
npm run dist:portable # 免安装版
npm run dist:all      # NSIS + 免安装，x64
```

## 核心概念

- **任务状态机**：`Idle → Running → Paused → Stopped`，不同状态对应不同的界面样式与可响应操作。
- **热键分层**：纯键盘热键通过 Electron `globalShortcut` 注册；含鼠标按键的热键通过 `uiohook-napi` 做系统级监听。
- **生效判定**：任务快捷键触发需同时满足「所属互动分组 = 启用分组」且「任务自身处于启用状态」。
